# 📚 Bookmarks

> A modern, full-stack web application for discovering books, building reading collections, and sharing community reviews.

---

## 🚀 Overview
**Bookmarks** is an interactive web platform designed for book enthusiasts to discover new reads, track their reading journey, and share ratings with a community of readers. Powered by real-time data from external book APIs and a Firebase backend, Bookmarks offers seamless search, custom bookshelf organization, and interactive rating meters.

## ✨ Key Features
* **🔍 Dynamic Book Search:** Instant book querying powered by the Open Library / Google Books API with debounced search optimization.
* **⭐ Interactive Rating Meter:** Visual star-rating system that dynamically calculates and updates average book ratings.
* **💬 Community Reviews:** Public discussion feeds allowing users to write, view, and interact with book reviews.
* **📚 Personal Collections:** Organize your personal library into three core shelves: *Want to Read*, *Currently Reading*, and *Read*.
* **🔐 Secure Authentication:** Seamless user login and profile persistence powered by Firebase Auth.

## 🛠️ Tech Stack
* **Frontend:** React.js (Vite), Tailwind CSS, Lucide React Icons
* **Backend & Database:** Firebase Authentication, Cloud Firestore
* **External APIs:** Open Library API / Google Books API
* **Deployment:** Vercel
